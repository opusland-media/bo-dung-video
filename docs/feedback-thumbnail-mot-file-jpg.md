Mỗi thumbnail/ảnh bìa xuất **2 file**: `.png` (gốc, nét) để user đăng Facebook và TikTok, `.jpg` (quality ~90, <2 MB) để dùng làm thumbnail YouTube.

**Why:** 13/11/2026 user hỏi vì sao luôn có 2 ảnh. Em giải thích rồi định bỏ png, nhưng user nói "để png để tôi đăng face và tiktok".

**How to apply:** giữ cả 2. Khi gửi thì nói rõ file nào dùng cho nền tảng nào. Liên quan [[feedback-cover-thumbnail-style]].

**Bảng tính / ảnh gửi khách (13/11/2026):** chỉ xuất **1 file .png nét** (render scale 1.5). Không kèm .jpg. User nói: "làm cái png nét dc rồi, khỏi cần cái jpg".
